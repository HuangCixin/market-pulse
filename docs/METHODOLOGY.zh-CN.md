# 方法说明

[English](METHODOLOGY.md) · **中文**

本文档解释 Market Pulse 网页上每一个数字的含义以及背后的设计选择。

## 1. 每日涨跌

每个市场都使用自己的交易日历，只在该市场实际交易的相邻两天之间计算涨跌。

| 市场类型 | 每日涨跌 | 显示方式 |
|---|---|---|
| 价格类（指数、商品、外汇、加密货币、VIX） | 对数收益率 `ln(Pₜ / Pₜ₋₁)` | 百分比，`(e^r − 1) × 100` |
| 收益率类（`kind: yield`，如美债 10 年） | 百分点变化 `Yₜ − Yₜ₋₁` | 基点（× 100） |

收益率不是价格：从 4.00% 升到 4.10% 是上升 10 个基点，而不是 2.5% 的收益。

**节假日不会被向前填充。** 如果用前一天的价格填补休市日，会制造出虚假的 0% 涨跌，从而把波动率和相关性压向零。

## 2. σ：这次涨跌有多异常？

同样是 1% 的涨跌，对欧元和对 Solana 意义完全不同。因此网页上所有涨跌也都用标准差（σ）表示：

```
σ 涨跌 = 该周期内的涨跌 / (日波动率 × √n)
```

- **日波动率**：该市场此前 60 个交易日（至少 20 个）日涨跌的标准差，只使用当天*之前*的数据，
  这样大幅波动的一天不会“稀释”自己。
- **n**：该周期内该市场的交易日数（日 = 1；周约为 5，加密货币为 7；月约为 21）。

经验法则：±1σ 属于正常，±2σ 属于异常，超过 ±3σ 则很少见。

**最新主要交易日。** 网页和要点默认显示至少一半市场开盘的最近一天，因此周六（只有加密货币交易）
不会被当作“今天”。

## 3. 相关性

相关性基于每日涨跌计算，而不是价格水平。两条同样上涨的价格曲线看起来相关，但它们每天的涨跌可能毫无关系。

- **只取工作日。** 计算相关性前，所有市场（包括加密货币）都只取周一到周五的数据。
  这样加密货币周一的涨跌与股票一样覆盖“周五 → 周一”。
- **成对完整观测。** 每一对市场只使用两者都开盘的日子。
- **时间窗口：** 60 个交易日（“近期”）和 250 个交易日（“常态”，约一年），可在 `config.yaml` 中修改。
- **关系发生变化** 列出 60 天与 250 天相关系数差距最大的市场对。
  “方向反转”表示符号改变，且两个数值都超过 ±0.1。

## 4. 美股 → 中国股市的次日传导

上海、深圳在北京时间 15:00 收盘，香港在 16:00 收盘，都早于纽约开盘。所以美股在第 *t* 天的涨跌，
只能在第 *t + 1* 天反映到中国市场。同日相关性会低估这种联系，因此该表计算的是最近 60 天内
“美股前一个交易日的涨跌”与“中国市场当天涨跌”之间的相关性。

## 5. 3D 布局

市场按**资产类别固定分区**摆放，分区在 `config.yaml` 的 `zones:` 中定义：金属、外汇、中国股市、能源、
美股与美债、加密货币。每个分区有自己的颜色，用于地形图上的圆圈、市场圆点和图例。

- 分区按配置中的顺序从左到右排列，每行三个。
- 分区内的市场排成一个小圆圈，围绕分区中心。
- 没有列入任何分区的市场，会按它的 `group` 自动生成一个分区。

布局每天都一样，同一个市场总在同一个位置。市场之间的联动关系由关联线、相关性图表和“美股 → 中国股市”表展示。

## 6. 地形曲面

高度和颜色都表示 σ 涨跌（高度限制在 ±4σ，颜色限制在 ±3σ）。

曲面在 56 × 56 的网格上绘制，每个网格点的高度是各市场 σ 的加权混合：

```
h(p) = Σ wᵢ σᵢ / (Σ wᵢ + K₀)        wᵢ = exp(−dᵢ² / 2s²) / (dᵢ² + ε)
```

- `1 / (dᵢ² + ε)` 这一项让曲面几乎准确地经过每个市场的数值。
- `K₀` 让远离所有市场的区域回到零（“海平面”）。
- 边缘逐渐回到零，使整个地形看起来是一个完整的整体。

**只有圆点是数据。** 圆点之间的曲面只是视觉辅助。两个上涨市场之间出现山谷，只说明那里没有市场。

颜色以零为中心向两侧发散：接近 0 为浅色中性，上涨为青绿色，下跌为橙红色。
在红涨模式（中国习惯）下两侧颜色互换。曲面使用简单的兰伯特光照，让坡度更容易看清。

## 7. “资金流向”与市场状态

这些都是**根据价格推断**的结果，并非资金流数据。

- **板块平均：** 板块内开盘市场 σ 涨跌的平均值。高于 +0.5σ 标为“流入”，低于 −0.5σ 标为“流出”，其余为“持平”。
- **市场状态得分**（最新主要交易日）：

  ```
  得分 = (2 × 股票平均 σ + 加密货币平均 σ) / 3 − 避险资产平均 σ
  避险资产 = 黄金、VIX、日元（美元/日元取反号）
  ```

  高于 +0.5 为“风险偏好上升”，低于 −0.5 为“避险”，其余为“分化”。

## 8. 盘中更新与实时价格

在线页面在工作日每 30 分钟重新生成一次，所以生成时有些市场还在交易。

- **交易时段。** 每个市场的交易时间写在 `config.yaml` 的 `sessions:` 里（交易所当地时间）。期货是隔夜时段，
  在交易日前一天傍晚开盘（芝加哥 17:00）。外汇按伦敦的自然日，加密货币按 UTC 自然日。没有交易所节假日表。
- **没走完的日线。** 如果生成页面时某个市场正在交易，并且它最新的日线属于当前这个交易时段，这根日线就“没走完”。
  它会显示在地形图、条形图和表格里，并标为**盘中**。它的 σ 是“到目前为止的涨跌 ÷ 正常一整天的波动”。
  计算相关性、滚动相关性和美股 → 中国股市表格之前，会先去掉这些没走完的日线，就当这一天还没发生。
  它们也不会进入计算 σ 用的波动率，因为 σ 用的是这一天之前的波动率。
- **开盘之前。** 还没开盘的市场显示“未开盘”而不是“休市”。本该在交易、但当天还没有数据的市场
  （节假日，或数据还没发布）显示“暂无今日数据”。
- **页面状态。** 页面顶部显示生成时间（按看网页的人的时区），以及当时股市（美国、中国内地、香港）是否在交易。
  有更新的版本发布后，页面会提示刷新。
- **加密货币实时价格。** 浏览器里，比特币、以太坊和 Solana 的价格来自 Coinbase 公开行情（Kraken 备用）。
  对于当天日线还在形成的那个 UTC 日，每个实时价格 *p* 按和生成页面时完全相同的方法更新涨跌：
  涨跌 = ln(*p* / 该周期的参考价)，σ = 涨跌 ÷（此前 60 天波动率 × √交易日数）。地形图、条形图和表格最多每 5 秒刷新一次。
  如果页面比当前 UTC 日旧，图表保持生成时的样子，价格条改为显示行情源给出的 24 小时涨跌。
  要点和风险偏好判断以页面生成时为准。

## 9. 已知局限

- Yahoo Finance 数据有延迟且非官方。某个代码偶尔会取不到数据，此时报告会跳过它。
- 期货（黄金、原油、铜）存在合约换月。使用 `auto_adjust` 后影响较小，但不为零。
- σ 假设近期波动率代表“正常”水平。在一段平静期之后，一次中等幅度的涨跌也可能显示为很大的 σ。
- 交易时段是近似的（没有节假日表），定时任务有时会晚几分钟开始。
